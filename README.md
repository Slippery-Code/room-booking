# Agentic AI for Software Development: from idea to production

Workshop repository · JOIST Innovation Space, Larissa · Saturday 24 October 2026

## Before the workshop

**1. Install** [Node.js](https://nodejs.org) (LTS), [git](https://git-scm.com) and [uv](https://docs.astral.sh/uv/getting-started/installation/), and sign in to the AI coding agent you'll use (Claude Code, Codex, Copilot, Cursor, or similar).

**2. Run:**

```bash
git clone https://github.com/elolos/agentic-sdlc-workshop.git
cd agentic-sdlc-workshop
npm install
npm install -g @fission-ai/openspec@1.14.3
uv python install 3.12
npm run check
```

**3. Done** when the last line says **All set** or **Ready**.

Stuck, or seeing a ✗? See [workshop/SETUP.md](workshop/SETUP.md).
