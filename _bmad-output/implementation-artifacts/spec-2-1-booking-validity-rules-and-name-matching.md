## Intent

**Problem:** Nothing yet decides whether a requested Booking is sensible, so invalid times, days or Names could reach the calendar.

**Approach:** Add pure domain modules: `nameKey` for Name matching, a `Result` type with `DomainError`, and `createBooking(bookings, request, now)` that runs the validity checks (name, length/grid, window, past) and returns a new list on success.

## Boundaries & Constraints

**Always:** Domain stays pure (no React, no clock; `now` is an argument). Check order: name, length/grid (length first), window, past; first failure returned. Never throw on rule failure; never mutate input. `nameKey(name) = name.normalize('NFC').trim().toLowerCase()`. Stored Name is trimmed, casing kept. Window = `windowDates(now)`. A Slot is past when its date is today and `startSlot <= athensSlotIndex(now)`. The request carries its own `id` (generated by the caller).

**Never:** Overlap/allowance rules (Story 2.2), persistence, UI, new dependencies, touching `vite.config.ts`/`tsconfig.json`/workflows, `any`/`@ts-ignore`, user-facing strings in the domain.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Name keys | `"  Eleni K. "` vs `"eleni k."` | same key; blank/whitespace -> `''` | none |
| Blank Name | name `"   "` | `name_required` | even if other fields are invalid |
| Length | slotCount 0 or 5 | `bad_length` | none |
| Length ok | slotCount 1 and 4 | ok | none |
| Grid | startSlot -1, or start+count > 24 | `outside_grid` | none |
| Ends at 20:00 | startSlot 20, slotCount 4 | ok | none |
| Window | date today-1 or today+7 | `outside_window` | none |
| Window edges | today and today+6 | ok | none |
| Past | today, startSlot <= current slot | `in_past` | none |
| Future today | today, startSlot = current slot + 1 | ok | none |
| Athens midnight | instant 21:00Z (next Athens day) | window rolls to the new Athens date | none |
| DST | days spanning 2026-10-25 / 2026-03-29 | window/past use Athens dates and offsets | none |
| Valid | valid request | `{ ok: true, value: { bookings, created } }`, new array, trimmed Name | none |
